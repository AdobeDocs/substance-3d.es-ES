# Control de versiones del motor de Substance

Los materiales y modelos de Substance creados en el software de Substance solo se pueden usar en aplicaciones que admitan la misma versión del Substance Engine o una más reciente

Consulte las tablas siguientes para saber si un material de Substance o un modelo procedimiento de Substance se puede utilizar con la versión actual de su software. En las tablas no aparecen todas las cesiones de cada aplicación, solo las que tienen una actualización. Por lo tanto, si no se especifica ninguna versión, se seguirá utilizando la versión anterior del Substance Engine.

>[!NOTE]
>
> Para saber qué motor de Substance, bakeres o versión de desajuste automático se usa en las aplicaciones instaladas, usa **Ayuda > Acerca de**, y luego usa el menú desplegable **Información adicional** para obtener una descripción general completa.
