# ¿Cuál es la profundidad de bits de las texturas al horno?

>[!WARNING]
>
> **Pregunta**
> 
> ¿Cuál es la profundidad de bits de las texturas al horno?

>[!NOTE]
>
> **Solución : Substance Designer**
> 
> La profundidad de bits depende del formato de archivo de destino utilizado para guardar las texturas.

>[!NOTE]
>
> **Solución : Substance Painter**
> 
> Las salidas de panadería se generan como texturas RGBA de 16 bits. A continuación, la profundidad de bits final depende del formato de archivo de destino utilizado para guardar las texturas. El formato de archivo de 32 bits convertirá la información de entrada de 16 bits, pero no ganará más precisión.

>[!NOTE]
>
> **Solución : Kit de herramientas de automatización de Substance**
> 
> La profundidad de bits depende del formato de archivo de destino utilizado para guardar las texturas.
