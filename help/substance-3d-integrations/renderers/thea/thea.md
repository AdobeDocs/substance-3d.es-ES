# Thea

El conversor Substance™ le permite crear un material Thea a partir de un archivo SBSAR de Substance™. Puede utilizar los parámetros exportados con el archivo Substance™ para cambiar el aspecto de las texturas y ver también la previsualización del material Thea creado antes de guardar el resultado final.

El conversor Substance™ le permite crear un material Thea a partir de un archivo SBSAR de Substance™. Puede utilizar los parámetros exportados con el archivo de Substance para cambiar el aspecto de las texturas y ver también la previsualización del material de Thea creado antes de guardar el resultado final. Puede utilizar cualquier archivo SBSAR, pero con un material de Substance™ basado en la plantilla de PBR Metallic/Roughness, se asegura de que el material creado en Thea también sea físico.

Para obtener más información, visite los documentos de procesamiento de Thea . [Convertidor de Substance de procesamiento Thea](http://thearender.media/docs/fr/thea-substance-converter/menu)
