# Arnold

El material de superficie estándar de Arnold 5 ahora admite el flujo de trabajo metálico. Puede exportar los canales de documento desde Substance Painter cuando utilice el sombreador metálico predeterminado o simplemente utilizar las salidas del flujo de trabajo metálico del plugin de Substance de un material de Substance.

* Color base
* Rugosidad
* Metálico
