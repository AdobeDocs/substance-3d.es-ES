# Cambio de rojo para 3ds Max

## Substance en 3ds Max Plugin

El plugin substance admite Redshift mediante el ajuste preestablecido de procesamiento Redshift . Con este ajuste preestablecido se configurarán automáticamente las salidas del Substance conectadas a un material Redshift.
