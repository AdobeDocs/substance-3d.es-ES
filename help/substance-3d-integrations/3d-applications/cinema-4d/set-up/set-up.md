# Configuración

## Requisitos

Se requiere un Cinema 4D R16 o superior. Todas las versiones del producto excepto Cinema 4D Lite son compatibles.

Los archivos de Substance se pueden crear con [Substance Designer](https://www.allegorithmic.com/products/substance-designer).

## Instalación

## Windows

1. Cinema 4D no debe estar ejecutándose durante la instalación.
1. Ejecute el paquete de instalación automática.
1. Elija o compruebe la carpeta de destino. Esta debe ser la carpeta en la que se instaló Cinema4D, no la subcarpeta de complementos.
1. Haga clic en &quot;Instalar&quot;.
1. Después de una instalación correcta, se le dará la opción de iniciar Cinema 4D.

## MAC OS X

1. Cinema 4D no debe estar ejecutándose durante la instalación.
1. Suelte el archivo cld en la carpeta de plugins de Cinema 4D.
1. Comience la Cinema 4D como siempre.
