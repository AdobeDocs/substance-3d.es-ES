# Uso del complemento Substance

El complemento Substance se encuentra en el menú Complementos de Cinema 4D.

![](../../../assets/cinema-4d-1.png){width="500px"}

## Cargar recurso...

Utilice esta opción para cargar recursos de Substance en la escena. Solo se pueden cargar archivos de Substance (.sbsar). Si aún no aparece Substance Asset Manager, se abrirá automáticamente al importar el Substance correctamente. Este comando también se encuentra en Substance Asset Manager.

Durante la importación, es posible que se le pregunte si el Substance debe copiarse en la carpeta del proyecto.

![](../../../assets/cinema-4d-2.png){width="500px"}

* Si responde &#39;No&#39;, se almacenará en su escena una ruta absoluta al Substance.
* Si responde &quot;Sí&quot;, el Substance se copiará en la subcarpeta de texto de su proyecto y solo se hará referencia a él por nombre de archivo.

Este mensaje solo aparece una vez por importación (p. ej., al arrastrar y soltar varios Substance desde el Explorador o Finder).
