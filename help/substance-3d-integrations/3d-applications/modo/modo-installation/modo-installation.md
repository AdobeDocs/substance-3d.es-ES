# Instalación de Modo

Para instalar el plugin, simplemente arrastre el archivo LPK a MODO. Si no ha instalado un kit o el paquete de contenido MODO, es posible que aparezca un cuadro de diálogo en el que se le pida que cree las carpetas adecuadas. Una vez instalado el kit, verá un botón de Substance en la parte superior derecha de la interfaz de usuario de MODO.
