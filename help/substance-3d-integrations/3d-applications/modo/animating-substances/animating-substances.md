# Animación de Substance

## Animación de SubstanceTextures

Los parámetros avanzados se pueden animar como cualquier otro canal en MODO. Si está utilizando la variable Tiempo de Substance Engine ($time) para animar una sustancia, puede acceder a esta variable de motor específica en los Canales de usuario del Substance.\
Al animar este canal, puede controlar la animación si el Substance se crea utilizando la variable $time.
