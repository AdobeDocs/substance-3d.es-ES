# Trabajar con referencias

## Trabajar con referencias

Los materiales de Substance se pueden utilizar con escenas referenciadas. Sin embargo, si necesita desactivar una salida para un Substance en una escena de referencia, deberá eliminar manualmente las salidas. Si se desmarca la salida de las propiedades del Substance, no se eliminarán las salidas de los Substance a los que se hace referencia cuando se utilicen las preferencias de referencia predeterminadas de MODO.\
Para permitir que el material del Substance al que se hace referencia elimine sus propias salidas generadasPara eliminar manualmente las salidas, primero debe cambiar las modificaciones de referencia de la escena. Vaya a Elemento>Referencias>Editar modificaciones de referencia y defina Eliminaciones en &quot;Si lo permite el elemento&quot;. Esto le permitirá eliminar manualmente las salidas del Substance\
en el árbol del sombreador y en el explorador de clips de cualquier escena que se abra o se cree después de realizar este cambio.

Consulte la documentación de MODO para obtener más información sobre las modificaciones de referencia.\
<http://modo.docs.thefoundry.co.uk/modo/801/help/pages/modointerface/ImportReference.html>
