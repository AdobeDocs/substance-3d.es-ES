# Instalación

El plugin Substance en Maya también se instala oficialmente en el instalador Maya 2022/2020. Está habilitado para instalarse de forma predeterminada.

>[!NOTE]
>
> **Maya 2022**
> 
> **Windows**: C:\Program Files\Allegorithmic\Adobe Substance 3D para Maya\2022\
> **MacOS**: /Aplicaciones/Allegorithmic/Adobe Substance 3D for Maya/2022\
> **Linux**: /opt/Allegorithmic/Adobe Substance 3D para Maya/2022

>[!NOTE]
>
> **Maya 2020**
> 
> **Windows**: C:\Program Files\Allegorithmic\Adobe Substance 3D para Maya\2020\
> **MacOS**: /Aplicaciones/Allegorithmic/Adobe Substance 3D for Maya/2020\
> **Linux**: /opt/Allegorithmic/Adobe Substance 3D para Maya/2020

Además, el instalador de las últimas versiones del plugin se puede descargar desde la página [Substance 3D de Adobe para Maya](https://substance3d.adobe.com/plugins/substance-in-maya/).
