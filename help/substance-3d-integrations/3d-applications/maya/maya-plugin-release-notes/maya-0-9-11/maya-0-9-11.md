# Maya 0.9.11

**Cambios en Maya 2.0:**\
**Estabilidad**:

* Los atributos dinámicos del gráfico ahora se crean de forma nativa, no mediante código del editor de atributos
* Los nodos del Substance se pueden crear por lotes a medida que se inicializan sin necesidad de introducir datos en la interfaz de usuario
* El editor de atributos y el editor de propiedades son considerablemente más estables
* El rendimiento de la memoria mejoró significativamente, lo suficiente para habilitar salidas 8k en el motor de la GPU
* Los ajustes/preferencias ahora se guardan como un archivo de configuración independiente que se puede editar fácilmente fuera de Maya

**Scripting**:

* API de scripting sólida, con cualquier operación desde capturar información de entrada, gráfica y salida, hasta cargar paquetes sbsar, cambiar de gráfico y realizar cualquier operación preestablecida en el gestor de ajustes preestablecidos
* Código de interfaz de usuario diseñado para utilizar las mismas funciones que la API de secuencias de comandos públicas

**Características del Substance**:\
**Compatibilidad con ajustes preestablecidos:**

* Los ajustes preestablecidos incrustados establecidos en el diseñador se cargan en el administrador de ajustes preestablecidos
* Importar y exportar archivos sbsprs, incluidos varios ajustes preestablecidos
* Gestor de ajustes preestablecidos
* Compatibilidad con motor V7
* Ya funciona con el nuevo motor de Substance que se lanzará con Designer 2019.1
* Las salidas numéricas se representan en un atributo de salida maya en el
* Nodo Graph/substance, que se puede conectar a otros nodos en la hipersombra

**Sistema de flujo de trabajo:**

* Nuevos flujos de trabajo para Arnold, Renderman, VRay, Corona y más
* Extensiones de flujo de trabajo personalizadas en Python
* Desactive los scripts de flujo de trabajo de la hipersombra, configure un flujo de trabajo personalizado una vez y guárdelo
* Utilizar un flujo de trabajo con mapas de imágenes de Substance Painter

**Mejoras en la interfaz de usuario y la experiencia de usuario:**

* Archivo -> import .sbsar crea un nodo de substance
* Arrastre y suelte los archivos sbsar del explorador de archivos al hipersombreado para crear nodos de Substance 2
* Ahora, los atributos se disponen según las categorías establecidas en Designer

**Otras mejoras:**

* Las entradas de imagen ahora funcionan con nodos de procedimiento
* Ahora puede definir la velocidad de muestreo para los nodos de procedimientos para poder reducir o aumentar las entradas de imágenes de procedimientos
* Los nodos de salida ahora muestran información de salida codificada en Substance Designer
* Los nodos Substance/gráfico ahora pueden mostrar información gráfica (autor, etc.)
* Compatibilidad con la anulación de capas, como las anulaciones de conexión y las anulaciones de atributos
* Caché a disco selecciona el tipo de archivo exr para cualquier salida HDR, que son salidas con salidas flotantes de 16 bits, 16 flotantes o 32 bits
* Reflejo del antiguo complemento
* Al cargar una escena con el nuevo plugin, los antiguos nodos de gráficos y resultados se convertirán en nodos de substance 2 .
