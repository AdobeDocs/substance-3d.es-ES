# Maya 2.3

Cambiar lista:

* Se ha añadido un modo para habilitar el tamaño físico. Esto agregará los cálculos de proyección triplanar a la red de nodos y se puede activar y desactivar
* Se han añadido nuevos comandos de scripts, substanceUtilityActivatePhysicalSize para habilitar o deshabilitar el tamaño físico y substanceUtilityResetPhysicalSize para restablecer los valores de proyección si se modifican.
* Se ha añadido el comando substanceNodeGetPhysicalSize para adquirir el valor de tamaño físico de un gráfico.
* Se han añadido nuevas casillas de verificación y botones para habilitar/deshabilitar, así como para restablecer. Se ha añadido una visualización en el editor de atributos del tamaño físico de una gráfica de Substance.
* Se ha añadido la configuración para habilitar la función de tamaño físico globalmente
  * Si la función de tamaño físico está activada, los flujos de trabajo del procesador permiten crear esos nodos de proyección
* Se ha eliminado la compatibilidad con Maya 2017

1. 3 se libera para
1. Maya 2018, 2019, 2020, 2022 y 2023 en Linux, macOS y Windows
1. Maya LT 2018, 2019 y 2020 en macOS y Windows
