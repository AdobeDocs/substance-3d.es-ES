# Maya 2.1.2

Publicado el 2 de junio de 2020

Hoy hemos lanzado la versión 2.1.2 del plugin.

El único cambio que contiene es:

* Se ha corregido un error en Maya LT al crear una red de sombreador de rayas.

Esto también se publicó con Maya 2020.2 y se incluye en el instalador de Maya correspondiente.

Se lanza para las mismas plataformas, Maya 2017 - 2020 y Maya LT 2018 - 2020
