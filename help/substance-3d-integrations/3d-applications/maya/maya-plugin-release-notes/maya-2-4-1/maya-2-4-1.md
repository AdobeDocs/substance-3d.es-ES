# Maya 2.4.1

<b>Agregado/actualizado:</b>

* El complemento Maya ahora utiliza la GPU de forma predeterminada, lo que mejora significativamente el rendimiento y la velocidad de procesamiento.

<b>Corregido:</b>

* Se ha corregido el vínculo del menú Acerca del Substance del plugin Maya para redirigir a la página de notas de la versión adecuada, que ahora señala correctamente a https://helpx.adobe.com/substance-3d-integrations/3d-applications/maya/maya-plugin-release-notes.html.
* Se ha resuelto un problema en el plugin Maya por el que el valor de resolución mostrado no se actualizaba en la interfaz de usuario después de restablecer un material, lo que garantizaba que todos los valores, incluida la resolución, se restablecieran correctamente a sus estados predeterminados.

Maya 2.4.1 está disponible para Maya 2020, 2022 y 2023 en Linux, macOS y Windows
