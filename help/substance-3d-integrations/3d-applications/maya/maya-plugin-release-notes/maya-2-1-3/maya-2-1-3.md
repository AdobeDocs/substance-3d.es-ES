# Maya 2.1.3

Publicado el 17 de junio de 2020

Hoy, hemos lanzado la versión 2.1.3 del plugin.

2.1.3 Versión:

* El instalador ahora está firmado con SHA-256 en Windows
* Todos los archivos binarios del instalador se firman ahora en Windows
* substance\_link.dll y substance\_portal\_cli.dll ahora tienen información de versión/descripción en Windows
* Se ha añadido una opción de flujo de trabajo para la superficie estándar en Maya 2020

Esta versión está disponible para Maya 2017, 2018, 2019 y 2020 en Windows, Linux y Macos. También está disponible para Maya LT 2018, 2019 y 2020 en Windows y MacOS.
