# Houdini

>[!NOTE]
>
> Substance en Houdini es desarrollado por SideFX Labs.

El [Complemento Substance para Houdini](https://www.sidefx.com/tutorials/sidefx-labs-substance-plugin/) te permite cargar archivos de Archivo Substance (SBAR) en Houdini en COP. Esto le permite encadenar nodos Substance, alimentar el resultado de los Substance a todas las partes de Houdini (terrenos, materiales, geometría) y muchos otros flujos de trabajo. El plugin es mantenido por el equipo de SideFX Labs.

## Instrucciones de instalación

Para Houdini 17.5, el plugin se distribuye con el GameDevelopment Toolset\
[Instrucciones de instalación del conjunto de herramientas GameDevelopment](https://www.sidefx.com/tutorials/game-dev-toolset-installation/)

Para Houdini 18.0 el plugin se distribuye con SideFX Labs.\
[Instrucciones de instalación de SideFX Labs](https://www.sidefx.com/tutorials/sidefx-labs-installation/)
