# Descargar e instalar

Autodesk distribuye de forma nativa la última versión del plugin con la última versión compatible de 3ds Max. Si necesita una versión específica para una versión anterior, busque los enlaces de descarga a continuación.

* **Descargar para Autodesk 3ds Max 2027:** <https://www.adobe.com/go/substance3d-3dsmax-win-latest>
* **Descargar para Autodesk 3dsMax 2026:** <https://www.adobe.com/go/substance3d-3dsmax-win-2026>
* **Descargar para Autodesk 3dsMax 2025:** <https://www.adobe.com/go/substance3d-3dsmax-win-2025>
* **Descargar para Autodesk 3dsMax 2024** (versión de complemento 3.1.0.): <https://www.adobe.com/go/substance3d-3dsmax-win-2024>
