# Eliminación del complemento Substance

Puede eliminar los materiales de Substance antes o después de eliminar la carpeta de Adobe y el archivo Adobe.meta.

1. Cerrar la unidad. Es necesario cerrar Unity para quitar el complemento. Si el proyecto está abierto y se elimina el complemento, seguirá volviendo a importar la dll del motor.
1. Mediante un explorador de archivos, acceda a la carpeta Recursos y elimine la carpeta Adobe y el archivo Adobe.meta.
1. Reinicie Unity.
