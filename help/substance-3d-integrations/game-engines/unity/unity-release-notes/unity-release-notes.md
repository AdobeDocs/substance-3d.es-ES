# Notas de la versión de Unity

Actualmente admitimos el plugin Substance 3D de Adobe para Unity a partir de la versión Unity 3.0.0. Las versiones anteriores del complemento Substance 3D para versiones anteriores de Unity dejarán de utilizarse próximamente.

**Las versiones de Unity de la versión 2.2.0 a la 2.6.0 quedarán obsoletas pronto.**
