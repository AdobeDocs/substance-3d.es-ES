# Unity 3.0.0

Publicado el 27 de junio de 2021

Actualizado/agregado:

* Compatibilidad con Apple Silicon
* Nuevo tutorial de YouTube sobre cómo usar el complemento
* Nueva documentación de scripts
* Compatibilidad con control-z en el editor de Gráficos de Substance y en el editor de archivos principal de Substance
* Se ha mejorado el rendimiento al cargar un gran número de archivos sbsar.
* Compatibilidad con materiales de Substance con varios gráficos
* Se ha cambiado la interfaz de usuario para administrar gráficos de Substance
* API expuesta para cargar un ajuste preestablecido a través de C#
* Documentación en línea actualizada

Corregido:

* Error en la pantalla del inspector al pulsar una y otra vez el botón de aleatorización
* Entradas de texturas nulas que interrumpen actualizaciones del Substance
* Los botones de alternancia &quot;Generar todas las salidas&quot;, &quot;Generar asignaciones de Mip&quot; y &quot;Solo tiempo de ejecución&quot; no funcionan
* Problemas con los espacios de nombres
* Error de referencia nula al entrar en el modo de reproducción con el recurso de gráfico seleccionado
* Problema con HDRP y URP para la última versión 2021.3 LTS de Unity al utilizar solo materiales de tiempo de ejecución
* Problemas de rendimiento con archivos sbsar con múltiples entradas
* Errores &quot;El identificador ya se ha publicado&quot;
* Problema &quot;Se ha cambiado el azul al entrar en el modo de reproducción&quot;
* El problema del mapa de heightes con los archivos sbsar
* Problema con entradas de imagen que leen texturas ilegibles

Problemas conocidos:

* Solución para un problema de Mac por el que los canales R y B de las texturas de salida se invertirán
* Principales mejoras de rendimiento para Mac
