# Unity 2.2.2

## 2.2.2 Notas de la versión

**fecha de lanzamiento: 11/02/2019**

### Complemento principal:

* Se ha corregido un error por el que la GUI de textura predeterminada de Unity se sobrescribía al instalar el plugin Substance en Unity.
  * Se ha corregido un error por el que EditorApplication.delayCall se establecía provocaba problemas con otros complementos.
  * Se ha corregido un bloqueo que se producía al utilizar caracteres no latinos en un nombre de proyecto
