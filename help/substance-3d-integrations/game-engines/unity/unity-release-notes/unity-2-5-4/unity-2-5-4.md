# Unity 2.5.4

Publicado el 9 de diciembre de 2020

Corregido:

* No se pueden generar aplicaciones de iOS compatibles con bitcode cuando los materiales de Substance se incluyen en un proyecto de Unity

Problemas conocidos:

* No se pueden descargar los recursos de Source en Unity de forma coherente. La solución alternativa consiste en descargar desde el [sitio web de Substance Source](https://source.substance3d.com/) e importar manualmente los recursos.
* Unity 2020.2 y versiones superiores no se admite actualmente
