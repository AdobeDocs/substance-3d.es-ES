# Astillero

![](../../assets/lumber.jpg){width="800px"}

El Substance Engine trabaja en Lumberyard Packaged Builds para Windows, Mac, PS4 y Xbox One. El plugin Substance también es compatible con todas las versiones del editor Lumberyard (Windows y Mac).

El complemento está integrado de forma nativa en el motor.
