# Imagen de entrada de Substance - UE4

El Substance se puede crear con entradas en las que se puede proporcionar una imagen para procesarla en el material. Esto le permite crear materiales modulares que pueden tomar datos o patrones de malla horneados como entrada para cambiar o conformar el material con el activo. Para utilizar una textura como entrada de sustancia, debe importarse a UE4 como textura de entrada de Substance.

1. Importe la textura en el Navegador de contenido. Para el formato, elija Entrada de imagen del Substance (jpg, tga, jpeg).
1. Esta textura ahora se puede utilizar con una entrada de Substance.
