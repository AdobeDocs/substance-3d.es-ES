# Complemento irreal 4.25.0.5

Añadido:

* Compatibilidad con Substance Engine v 8.0.3
* La acción del Substance Source ahora accede a la pestaña Origen dentro del Iniciador de Substance, lo que permite enviar los recursos directamente a UE4 ([más detalles](../../../../../game-engines/unreal-engine/unreal-engine-4/source-in-ue4/source-in-ue4.md))
* Se ha reducido el número de materiales de Substance procesados a la vez que se actualizan las versiones del proyecto

Corregido:

* UE4 se bloquea en Mac al cerrar el editor con el plugin UE4 Substance instalado
* Al cambiar el parámetro de texto en una instancia de Gráfico de Substance, se produce un bloqueo y un bloqueo final.
