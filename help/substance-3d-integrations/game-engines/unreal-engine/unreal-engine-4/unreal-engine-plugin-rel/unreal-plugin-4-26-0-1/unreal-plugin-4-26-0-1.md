# Complemento irreal 4.26.0.1

Esta es una versión para compatibilidad con UE4.26.

Problemas conocidos:

* No se pueden descargar los recursos del origen en UE4 de forma coherente. La solución alternativa consiste en descargar desde el [sitio web de Substance Source](https://source.substance3d.com/) e importar manualmente los recursos.
