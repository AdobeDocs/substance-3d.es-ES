# Motores de juegos

Puede importar un archivo de Substance (.sbsar) en la mayoría de los motores principales a través del complemento de Substance.

* <b>Unity</b> tiene el complemento de substance integrado de forma nativa para el ciclo de lanzamiento de 2017. Para Unity 2018 y versiones superiores, el complemento Substance está disponible en [Unity Asset Store](https://assetstore.unity.com/packages/tools/utilities/substance-in-unity-110555).
* El complemento <b>Unreal Engine</b> se encuentra en [Unreal Marketplace](https://accounts.unrealengine.com/logout?redirectUrl=https%3A%2F%2Fwww.unrealengine.com%2Fmarketplace%2Fsubstance-plugin).
* El complemento <b>Lumberyard</b> está integrado de forma nativa.
* El complemento <b>CRYENGINE</b> está integrado de forma nativa y Crytek lo mantiene. Para obtener más información, consulte la [documentación de Substance CRYENGINE](https://docs.cryengine.com/pages/viewpage.action?pageId=44968527)
